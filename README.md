# 2026 retreat flash talk

Open `index.html` in Chrome (keep the `media/` folder next to it).
F = fullscreen · arrows / space / clicker = next/previous · R = replay movie.
`flashtalk_backup.pdf` is a still-image backup of the same slides.

`web/` has the 2DTM movie for websites: no text, transparent background,
1800×886. Use `2dtm_lysate.webm` in `<video autoplay loop muted playsinline>`
with `2dtm_lysate_poster.png` as poster; Safari has no VP9 alpha, so show
`2dtm_lysate.webp` there instead.
